# Notea Workspace — Database Schema

Last updated: 2026-09-15. Status: **designed** (M1 implements the first four tables). Postgres 17, Drizzle ORM in `packages/db`. Ids are UUIDs generated by the application (`crypto.randomUUID()`); timestamps are `timestamptz`.

## What is *not* in the database

- Runtime state (running/stopped) — Docker is the source of truth; the control plane asks the orchestrator and may cache `last_known_status` for list views.
- Terminal sessions and presence — live in the workspace agent.
- Project knowledge — lives in the repository.

## Drizzle sketch (M1 tables)

```ts
export const users = pgTable('users', {
  id: uuid('id').primaryKey(),
  email: text('email').notNull().unique(),      // use citext via custom type or lower() unique index
  name: text('name').notNull(),
  passwordHash: text('password_hash'),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
});

export const workspaceRole = pgEnum('workspace_role', ['owner', 'editor', 'viewer']);

export const workspaces = pgTable('workspaces', {
  id: uuid('id').primaryKey(),
  slug: text('slug').notNull().unique(),
  name: text('name').notNull(),
  ownerId: uuid('owner_id').notNull().references(() => users.id),
  image: text('image').notNull().default('notea/workspace:dev'),
  resources: jsonb('resources').$type<Partial<WorkspaceResources>>(),
  repoUrl: text('repo_url'),
  lastKnownStatus: text('last_known_status'),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  deletedAt: timestamp('deleted_at', { withTimezone: true }),
}, (t) => [index('workspaces_owner_idx').on(t.ownerId)]);

export const workspaceMembers = pgTable('workspace_members', {
  workspaceId: uuid('workspace_id').notNull().references(() => workspaces.id, { onDelete: 'cascade' }),
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  role: workspaceRole('role').notNull(),
  invitedBy: uuid('invited_by').references(() => users.id),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (t) => [primaryKey({ columns: [t.workspaceId, t.userId] })]);

export const workspaceEvents = pgTable('workspace_events', {
  id: bigserial('id', { mode: 'number' }).primaryKey(),
  workspaceId: uuid('workspace_id').notNull().references(() => workspaces.id, { onDelete: 'cascade' }),
  actorKind: text('actor_kind').notNull(),
  actorId: uuid('actor_id'),
  type: text('type').notNull(),
  payload: jsonb('payload').notNull().default({}),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (t) => [index('workspace_events_ws_idx').on(t.workspaceId, t.id)]);
```

## Invariants

- A workspace's `id` is what the orchestrator knows; deleting a workspace calls `DELETE /workspaces/:id?deleteVolume=true` first, then soft-deletes the row.
- Every workspace has exactly one `owner` member row.
- Roles in the database and in connect tokens use the same string values as the protocol.

## Migrations

`drizzle-kit generate` produces SQL under `packages/db/drizzle/`; `drizzle-kit migrate` applies them. Development database: `docker compose up -d postgres` (host port 55432, because 5432 is occupied on the dev machine by another project's container).
